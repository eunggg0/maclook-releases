# MacLook 다운로드

애플 실리콘 맥북용 모니터링 + 팬 제어 + SSD 주치의 메뉴바 앱.

## 설치

1. [Releases](https://github.com/eunggg0/maclook-releases/releases)에서 최신 `MacLook-x.x.x.zip` 다운로드
2. 압축 풀고 `MacLook.app`을 응용 프로그램 폴더로 이동
3. **첫 실행만 우클릭 → 열기** (무료 배포라 애플 공증이 없어 경고가 한 번 뜹니다)

## 업데이트

앱이 새 버전을 자동으로 알려줍니다. 설정 → 정보 → "지금 업데이트" 버튼 한 번이면 끝. 설정은 유지됩니다.

## 요구 사항

- Apple Silicon (M1~M5), macOS 15+
- SSD 건강정보(SMART): 팬 제어 활성화(관리자 암호 1회)와 함께 자동으로 켜집니다 — 별도 설치 불필요
- 동봉된 smartctl은 smartmontools(GPL-2.0)의 실행 파일입니다 (앱 내 고지 포함)
